Tarea 1 — Primera escena con marcador

Esta tarea consiste en crear una primera experiencia básica de realidad aumentada en una página web. El objetivo es que, al enfocar un marcador con la cámara del móvil, aparezca sobre él un objeto 3D sencillo (un cubo), comprobando que todo el sistema funciona correctamente.

Para ello, se utilizan A-Frame para construir la escena 3D y AR.js para detectar el marcador. Además, se organiza el trabajo en dos páginas separadas: una para la experiencia de realidad aumentada y otra para mostrar las evidencias del proceso.

También se prueba la experiencia en el móvil, se capturan imágenes como prueba y se publica todo en GitHub Pages. Esta tarea sirve como base para futuras prácticas más complejas de realidad aumentada.
